# 独修者的灯 2.0 · 剧本规格（写剧本的人必读）

## 0. 目标（用户反馈）
- 旧版：每章像讲课，一直灌知识点，没玩法；剧情单一；太简略，一章看完不知道看了什么。
- 新版：**知识要在“解决一件事”的过程里出现**；每一节都有动手的玩法；人物有冲突、有变化；
  每章开头有“导读卡”（intro），结尾有“本章笔记”（journal），让玩家清楚自己读了什么。
- 节奏：慢一点、具体一点。少用“作者认为……”式的讲课句，多用场景、动作、对话、玩家选择。
  守灯人**不是讲师**：她常常反问、让玩家自己去看、自己去翻书（探索/试炼）。
- 准确性：所有书中观点必须出自 notes（见下），引用页码用印刷页码，写成 `p.39`。
  OCR 缺字的地方不要补写。作者个人观点要说成“书里/作者这样说”，不是“所有威卡都这样”。
  不要写成传教；尊重怀疑者，不嘲笑任何宗教。

## 2. 世界与人物（所有章节统一）
- 地点：北方山村。屋后坡上有一圈立石（石圈）。坡下有林子、湖、守灯人的小屋（书房/桌）。
- 时间线：序章是十月一个月夜。第1–7章发生在接下来的几周（深秋到初冬，满月前后）。
  第8章是“一整年”：从冬至走到下一个萨温（Samhain）。第9章紧接萨温之后。
  第10章在次年圣烛节（Imbolc，2月2日）前后，以黎明时的自我献身仪式收尾（书里说 Imbolc 传统上是入门/自我献身的时节，p.68）。
- 人物（`who` / `name` / `por`）：
  - 你（玩家）：`who:"player"`, `name:"你"`，无立绘。村里长大的年轻人，好奇但谨慎。
  - 守灯人：`who:"keeper"`, `name:"守灯人"`, `por:"keeper"`。年长女性，独修多年，话少、幽默、常反问。
    她不收徒，不要钱，不传教。她会说“你自己翻到那一页看看”。
  - 老陈：`who:"chen"`, `name:"老陈"`, `por:"skeptic"`。种地养牛的中年人，怀疑、嘴硬、心软。
    担心你“学坏”。线索：走失的母牛（第1章找到）→ 母牛怀孕 → 欠兽医钱 → 圣烛节产小牛（第8章）→ 关系慢慢变好。
    他不需要“皈依”，结局里他只是愿意坐下来聊天。
  - 阿禾：`who:"he"`, `name:"阿禾"`, `por:"he"`。老陈的侄女，十七岁，急性子，想“马上学会魔法”。
    第2章末出场。第3章要你教她让喜欢的人（小满）爱上她 → 伦理冲突。第5章不好意思跳舞。
    第6章丢了“幸运手链”就慌了。第8章萨温想召唤去世的母亲。第9/10章她自己做选择（可能继续学，也可能决定这不是她的路——两种都应被尊重）。
  - 白先生：`who:"bai"`, `name:"白先生"`, `por:"bai"`。走村串乡的货郎，口才好，
    卖“祖传原版影之书”“开过光的法刀”，收费“入会”，自称前世是名人。他是书中各种误解的化身。
    第4章初次出现，第7章、第9章再遇，第10章摊牌（辩论试炼）。他不是恶魔，只是生意人；结局他离开村子。
  - 小满：只被提到，不出场（阿禾喜欢的人）。
  - 女神 / 男神：`por:"goddess"` / `por:"god"`，只在幻视中出现，不说长话（多用“……”）。
- 关系值：`rel` 指令，`who` 取 `chen` / `he` / `bai` / `keeper`。玩家体贴、讲理、不说教时加分。
  每章给 1–3 次加减机会。结局用 `relMin` 判断。

## 3. 文件与结构
每位作者写一个文件：`D:\下载\pixel-wicca-v2\src\story\chXX.js`，内容格式：
```js
STORY_ADD({
  scenes: { "c5_dance": { title, bg, music, script: [ ... ] }, ... },
  codex:  { "gesture4": { cat:"第五章", title, en, text, src }, ... },
  trials: { "t5_instruments": { kind:"sort", ... }, ... },
  sigils: { "hand": { name, icon, desc, src } },
  achv:   { "dancer": { name, desc } }
});
```
- 文件必须是**合法 JS**（用 JSON 风格，双引号）。中文引号请用「」或“”，不要在字符串里出现未转义的 `"`。
- 场景 id 必须以章前缀开头（`c5_`），flags 也用章前缀（`c5_shy`），试炼 id 用 `t5_`，日记 id 用 `j_c5` 等。
- 每章的**入口场景 id 固定**（见第6节），章末用：
  `{"t":"finishChapter","id":"c5"}`, `{"t":"chapter","title":"第六章","sub":"…","en":"…"}`, `{"t":"scene","id":"c6_prep"}`。
  入口场景开头**不要**再放 chapter 卡（由上一章末尾放），但要放 `intro` 导读卡。
- 写完后运行：`node D:\下载\pixel-wicca-v2\tools\validate.mjs`，修到 0 错误。

## 7. 小游戏（trials）
通用字段：`kind`, `title`（≤ 16 字，形如“第五章 · 四方之手”）, `explain`（结算说明 ≤ 90 字）, `src`（如 `"Chapter 5 · p.45"`）。

- `quiz`：`questions:[{q, options[4], answer, explain, src}]`。q ≤ 50 字，选项 ≤ 28 字。3–5 题。
  适合“辩论”：q 写对方的说法，选项是你的回应。
- `multi`：`q, options[≤8], answers[], explain`。选项 ≤ 28 字。
- `sort`：`bins:[{id,label(≤6字),tip?(≤8字)}]`（2–4 个箱）, `items:[{text(≤40字), bin, why, src}]`（5–8 条）。
- `match`：`pairs:[{left(≤8字), right(≤15字), note}]`（4–6 对）。
- `order`（新）：`caption, items:[{id, label(≤14字), why?}]` —— **按正确顺序列出**，游戏里会打乱。4–8 项。
- `arrange`：`caption, items:[{id, icon, label(≤5字), why, src?}], slots:[{x,y,label(≤7字),item}]`。
  slots 坐标在 480×270 里，范围 x 70–410，y 70–185；两槽中心至少相距 70（横）/ 48（竖）。≤ 8 槽。
  例：四方——北(240,78) 东(330,128) 南(240,178) 西(150,128)；年轮 8 个点可放在圆上（圆心 240,128，半径横 120 竖 52）。
- `rhythm`：`caption, speed(90–150), lead(1.2), notes:[毫秒时刻]`（10–20 个，间隔 ≥ 380ms）, `window`(默认 26)。
- `breath`（新）：`caption, cycles(3–5), inhale(秒), hold(秒,可0), exhale(秒)`。吸气时按住空格/鼠标，呼气时松开。
- `trace`：五角星那种按顺序连点（一般不用新做）。

## 8. 每章最低配置
- 开头 1 个 `intro`；正文 2–4 个场景（scene），总计 120–220 步。
- 至少 2 次 `explore`、3 个不同类型的试炼、2 次有后果的 `choice`（设 flag / rel，后面要用到）。
- 6–12 条 `quote`（真正有意思的句子，别堆砌）；8–14 条 codex。
- 章末 1 页 `journal`（id `j_cN`，title 如“第五章 · 本章笔记”）：4–7 行，用大白话总结
  “这一章讲了什么、我做了什么、我还有什么疑问”，可用 when 根据玩家选择变化。
- 守灯人每次讲解别超过 2 句连在一起；穿插玩家动作、回问、旁白描写。
- 单句长度：say/narr ≤ 80 字（有立绘时 ≤ 70 字），think ≤ 50 字，quote 中文 ≤ 100 字、英文 ≤ 280 字符。
