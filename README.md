# 独修者的灯 · 2.0

一本能玩的《威卡：独修者指南》。单文件像素风网页游戏，双击就能玩，不联网、不装东西、不含任何素材文件。

## 开始游戏

双击根目录 `index.html` 或 `dist/index.html`（两者内容一致）即可离线游玩。
按回车或点击推进；选择题用方向键与回车，也可以直接点击。
右上角四个按钮分别是菜单、章节地图、图鉴、符印；设置里可分别调整音乐、音效，或静音。

### 手机 / 平板

同一个文件直接丢进手机浏览器、微信（用浏览器打开）或平板 Safari 都能玩，**不需要服务器**：

- **请横屏玩**。窄屏手机竖屏时会盖一层「请把设备横过来」的提示；
  平板竖屏画面仍有 749×421，可以直接玩。
- **整块屏幕都是触摸区**：点对话框任意位置推进（右侧空白也算），
  点右上角按钮开菜单/章节/图鉴/符印，点标题菜单项开始游戏。
- **探索环节可以滑动**：按住手指在画面里移动，选中会跟着手指走，抬起来才算点击，
  避免误触。点头位框、点底部「继续」都能推进。
- 适配了刘海屏安全区（`env(safe-area-inset-*)`）与浏览器手势条，
  横屏 iPhone 左右各约 44px 的圆角区不会盖住 HUD 按钮。
- 禁用了滚动、双击缩放、长按选择；点了按钮会尝试给一次 8ms 轻微震动
  （`navigator.vibrate`，不支持的浏览器直接忽略）。
- 小屏上**整数缩放会自动让位**：手机横屏 844×390 时 `floor(1.44)=1`
  会让画布只剩 480×270、四周大片黑边，所以这种情况下自动改用小数缩放填满
  （672×378）。桌面 1280 / 1920 宽仍走整数倍，像素完全对齐。
- 设置里新增两项：**屏幕震动**（可关，部分人对画面抖动敏感）、
  **坐标读数**（排障用，桌面也可按 `/` 开关）。

## 内容

- **十二章一条主线**：序章 → 第一章到第十章 → 尾声。约 1900 步剧本、47 个场景。
- **45 个小游戏**：分类、配对、排序、排列、节奏、呼吸、多选、问答等。
- **147 条图鉴、14 个符印、18 个成就**；关系值影响人物结局。
- 知识内容依据 Scott Cunningham《Wicca: A Guide for the Solitary Practitioner》。
  引文的英文为原书逐字原文（`quote.en`），页码用印刷页码；OCR 缺页处不补写
  （第 48 页泡烂那一段就是照这个处理的）。

## 怎么改

```
src/engine.js      流程、存档、输入、探索界面、结局
src/ui.js          对白框、选择支、试炼（14 种玩法）、图鉴、地图、设置
src/art.js         绘图原语、背景、参数化小人、图标、像素字体加载
src/audio.js       七首三拍子配乐与三种变奏、16 个音效（全部实时合成）
src/story/base.js  章节表 + STORY_ADD 合并函数
src/story/ch00.js… 各章剧本（ch00 序章，ch01–ch10，尾声在 ch10 末尾）
docs/STORY_SPEC.md 剧本规格（指令表、坐标、试炼字段、字数限制）
docs/CHAPTER_BRIEF.md 写手用的作者简报（能力白名单、跨界旗标契约）
docs/REVIEW_NOTES.md  一轮内容审读的结果（引文核对、跨章矛盾）
tools/validate.mjs 剧本校验
tools/*.html       五套无头验证台架
```

改完剧本后重建单文件：

```powershell
node build.mjs          # art/*.png → base64、字体子集、内联全部脚本 → index.html 与 dist/index.html
node tools/validate.mjs # 0 错误才算合格
```

`src/art-data.js`、`src/font-data.js` 由 `build.mjs` 生成，不要手改。


### 界面可点范围（设计如此，不是 bug）

- **对话框：整个框都能点**（含右侧空白）。点击行为是两段式：还在打字时点一下 → 立刻补全；
  字已打完再点 → 下一句。框右下角有闪动提示（打字中显示"点击补全"，打完显示"空格 / 点击"）。
- **探索界面**：点位框、底部"继续"按钮可点（框外 3~8 像素内在容错范围内也算命中）。
- **标题页菜单 / 图鉴列表 / 章节地图**：只有**左侧有内容的那块**可点，右半屏是空白。
  文字只有左半边可点，右半边完全没用——这是刻意的，因为右侧没有可交互内容。
  按 `M` / `B` / `C` 可以直接切章节/图鉴/符印，比点按钮快。

### 两条实测限制（写在这里，免得下次又踩）

1. **音频台架没用 `OfflineAudioContext`**：Chromium 无头下，一条轨道排到 4 小节
   （上百个带周期波的振荡器）时 `startRendering()` 会永远停在 `state='running'`；
   1 小节 23ms 却正常。`--headless=old/new`、`--mute-audio` 都试过，一样。
   所以 `audio-check.html` 改成**确定性的 PCM 模型**：谱面与音效配方从 `src/audio.js` 原文解析，
   合成与包络按 `note()/schedule()/cues` 逐行等价实现。它证明"谱面有声音、音量合理、基准线为 0"，
   不证明浏览器 DSP。
2. **无头浏览器不会推进 `<audio>` 的时间轴**：媒体元素能加载（`readyState` 到 4、`duration` 正确），
   但 `currentTime` 停在 0。所以 `music/` 那套外部配乐**只能在真实浏览器里人工验收**，
   无头只能验到"文件被探测到、元素被创建、音量被正确设置"。
   另外：外部配乐层刻意**不走 WebAudio 路由**（不用 `createMediaElementSource`），
   那种做法在没有音频设备的环境里会卡成"看着在播、永远不出声"。
3. **点阵中文字体在 480px 画面上是密排的**：一个汉字只有 12 像素见方，
   句子长了笔画会相互贴近（放大看是"连笔"）。这是分辨率决定的下限，换字体解决不了，
   只能靠"把虚拟分辨率提到 640×360"这类大改。
   另外注意：`art.js` 里的 `THRESHOLD` 是给硬网格点阵字体准备的二值化开关，
   当前正文字体（乐米像素体）自带抗锯齿，**必须保持 0（关闭）** ——
   开成 110 会把灰边切成毛刺，反而更糊（有 A/B 对比图）。

### 改字体 / 改字号时的注意点

`src/art.js` 的 `spec()` 把逻辑字号映射到实际渲染档位，其中 **10 与 12 在同一档**
（字形高都是 11px）。这是有意的：12px 是对话框正文用的字号，
把 12 的档位往上调会把正文放大一倍，是灾难。想让某处"看起来更大"，
用更大的逻辑字号（16 / 24 / 30）或换颜色，**别动那个边界**。

改完字体或字号，用 `tools/glyph-metrics.html` 量一下各字号真实的字形高度，
再核对排版行距 —— 文字重叠基本都是"字形比行距高"造成的。

## 换成自己的配乐（可选）

游戏**优先播 `music/` 文件夹里的真实配乐**，没有该文件时自动回落到内置合成曲 ——
所以不丢音乐也照样是"单文件双击可玩"。

把音乐按场景 id 命名丢进 `music/` 即可（`mp3` / `m4a` / `ogg` / `wav` 都认）：

```
music/title.mp3    music/forest.mp3   music/cottage.mp3  music/moon.mp3   music/dawn.mp3
music/trance.mp3   music/wheel.mp3    music/trial.mp3    music/ending.mp3 music/vision.mp3
```

- 曲子会**自动做首尾闭环**：播到还剩 2 秒时新起一份淡入、老的淡出，所以单曲能接成不露缝的循环。
  也正因为如此，曲子最好**全程同一力度、结尾不要落在终止和弦上**（Suno 提示词见 `docs/MUSIC_PROMPTS.md`）。
- **音乐默认只占 5% 音量**（设置里的"音乐音量"就是实际比例），音效 90% —— 因为实测音乐很容易盖过
  打字机之类的音效。想调大就在设置里拉，不需要改代码。
- 名字写错不会报错，只会静默回落到合成曲；想确认有没有被读到，看浏览器控制台的 `[配乐] music/ 里找到 N 首：…`。
- 这一层刻意**不走 WebAudio 路由**（不用 `createMediaElementSource`）：那种做法在无音频设备的环境里
  会卡成"看着在播、永远不出声"，直接播 + 手搓淡入淡出到处都能响。
- **同一时刻只有一套音乐在响**：探测到文件就立刻把内置合成曲压到 0，MP3 真出声时彻底停掉它；
  只有"文件加载报错"或"12 秒内既没播成也没等到用户手势"才把合成曲放回来。
  （浏览器要求先有一次用户手势才允许出声，所以第一次要点一下或按一下键。）

## 素材与授权

- **正文字体：乐米像素体**（`fonts/LemiPixel.ttf`，免费商用），构建时裁成子集内联。
  按 12px 原样渲染，**不做二值化**，保留字体自带的抗锯齿。
- 西文与数字：Fusion Pixel Font（SIL OFL 1.1，见 `fonts/OFL.txt`），同样子集内联。
- 画面：`art/*.png` 是像素背景与立绘，构建时 base64 内联，游戏运行时不再引用任何外部文件。
- 配乐与音效：全部由 `src/audio.js` 实时合成，没有音频文件。
